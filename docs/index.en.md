# Wocon Project Documentation

## Project Overview
Wocon is a travel-focused social application that helps users find like-minded travel companions and discover unique travel destinations. Our goal is to provide you with a one-of-a-kind solution during those uncertain moments when planning your trip.

## Core Features
- 🗺️ **Interactive Map**：Smooth map experience powered by Leaflet.js
- 🌍 **Destination Discovery**：Randomly explore popular travel destinations worldwide
- 📍 **Geolocation**：Get and display user's current location
- 👥 **Travel Companion Matching**：Find suitable travel partners based on interests and destinations
- 📋 **Trip Management**：Create, share, and collaborate on travel plans
- 🔍 **Location Search**：Quickly find tourist attractions and accommodations
- 🎨 **Modern Interface**：Elegant experience based on Google MD3 Design System

## Tech Stack
- **Frontend**：Vue 3 Composition API, TypeScript, Leaflet.js
- **Backend**：Supabase (database and user authentication)
- **Deployment**：Cloudflare Pages
- **Development Tools**：VS Code, Trae, GitHub, TablePlus
